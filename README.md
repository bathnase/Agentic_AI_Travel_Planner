# ✈️ Agentic AI Travel Planner

An AI-based travel planning assistant that generates trip itineraries using
flights, hotels, tourist places, live weather, and budget estimation.

## 🚀 Features
- Cheapest flight selection
- Best hotel recommendation
- Day-wise itinerary
- Live weather forecast (Open-Meteo API)
- Budget estimation
- Interactive Streamlit UI
- Optional LangChain agentic reasoning

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain (optional)
- Open-Meteo API
- JSON datasets
